# Reader example: Alice's Adventures in Wonderland

`pg11-images-3.epub` is the illustrated Project Gutenberg ebook #11 by Lewis Carroll.
Project Gutenberg identifies this edition as public domain in the USA. The source page and
the Project Gutenberg License are available at <https://www.gutenberg.org/ebooks/11>. The app's
fallback reader sample is the public-domain Lewis Carroll edition from Standard Ebooks.

The file is kept outside the app bundle and is fetched into the local personal library only as a
reader demonstration. It is not medical content and is not used by the search corpus.
