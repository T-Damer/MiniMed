# Live prototype smoke scope

The live smoke check is intentionally small and production-facing. It verifies that GitHub Pages exposes both prototype entry points, opens the psychology questionnaire bank, opens the medical calculator catalog, and completes a deterministic Mosteller body-surface-area calculation.

Detailed questionnaire scoring, patient-note persistence, formula regression, source metadata, and unit conversions remain covered by the normal unit and local Web E2E suites.
