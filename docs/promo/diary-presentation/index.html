Слепое окно между визитами

Что происходит дома, врач узнаёт только на следующем приёме — со слов пациента.

Бумага и мессенджеры не годятся

Бумажный дневник теряется или заполняется накануне визита. Мессенджер — небезопасное место для данных о здоровье.

Ухудшение замечают поздно

Побочные эффекты, скачки давления, плохие дни — врач узнаёт о них через недели, на приёме.

Стандарты и удобный интерфейс

Международный стандарт HL7 FHIR

Тот же «язык», что у современных медицинских информационных систем: файл из дневника можно загрузить в МИС без ручного переноса.

ПоказательМеждународный кодЕдиницы
Систолическое давление8480-6мм рт. ст.
Диастолическое давление8462-4мм рт. ст.
Пульс8867-4уд/мин
Сатурация SpO₂59408-5%

Коды — из международного справочника LOINC. Имени пациента в файле нет: врач сам сопоставляет его с картой.
