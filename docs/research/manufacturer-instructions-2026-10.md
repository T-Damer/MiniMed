## 4. Пилот

Команда (резюмируемый обход; состояние — `state.jsonl`, повторный запуск ничего не перекачивает):

```bash
uv run --project tools/ingest medbase-manufacturer-instructions crawl \
  --plan data/build/grls-instructions-active-plan-02.10.2026.json \
  --grls-state data/build/grls-instructions-active-state.jsonl \
  --catalog data/raw/official-grls-registry/catalog-02.10.2026.json \
  --grls-raw-root data/raw/grls-instructions-active \
  --site vertex --max-documents 60            # сайты: vertex promomed usolpharm microgen renewal akrikhin krka
uv run --project tools/ingest medbase-manufacturer-instructions rebuild-manifest …   # офлайн, переписывает manifest.jsonl
```

Сырьё и манифест: `data/raw/manufacturer-instructions/` (отдельный класс источника `manufacturer-site`, **не** смешан с `data/raw/grls-instructions-active`; файлы ГРЛС не трогались): `<сайт>/files/<sha256>.pdf|docx`, `<сайт>/pages/<sha256>.html` (страница-источник, нужна как доказательство), `<сайт>/text/<sha256>.json` (кэш извлечённого текста, восстанавливается), `state.jsonl` (журнал запросов), `manifest.jsonl`.

Строка манифеста: `sourceClass`, `publisherKind: manufacturer-site`, `publisher`, `sourceUrl`, `pageUrl`, `fetchedAt`, `sha256`, `bytes`, `contentType`, `httpLastModified`, `httpEtag`, `rawPath`, способ извлечения текста (`pdf_text_layer`/`ocr`/`docx`, движок OCR, число страниц OCR, средняя уверенность), `textChars`, `textLikelyGarbled`, `standardSectionMarkers`, `documentRevision` (версия/дата как напечатаны: «пересмотрен …», «от dd.mm.yyyy», дата в имени файла), и `matches[]`: регистрация, торговое название, уровень совпадения, доказательства.

### Извлечение текста и пригодность

Штатный путь `pdf_import.extract_pdf` (текстовый слой, macOS Vision OCR при отсутствии слоя; флаг сохранён). Из 373 документов: текстовый слой 320, **OCR 25 (6,7 %)** — в основном сканы со штампами у Вертекса и Реневала, DOCX 28. Нечитаемого текста (`textLikelyGarbled`) — 0; стандартные разделы (показания, противопоказания, способ применения, нежелательные реакции, состав, хранение) найдены полностью в 331 из 373 документов, в 34 — 5 из 6, в 8 — меньше (в т. ч. один документ почти без разделов). Тип документа по заголовку: ИМП 216, листок-вкладыш 122, ОХЛП 32, прочее 3. Дата/версия напечатана в тексте у 25 документов; `Last-Modified` сервера есть у всех (это дата файла на сайте, не дата редакции).

### Расхождение версий с ГРЛС (✔ выборка 32 пар, где РУ напечатан и ГРЛС-PDF у нас уже есть)

Сравнение 6-словных шинглов (Жаккар): для ИМП Реневала медиана ≈ 0,65 (0,03–0,92; ≥0,85 только 2 из 15), у ОХЛП КРКА 0,02–0,09 — это иной тип документа (ОХЛП против листка ГРЛС). Часть расхождения даёт OCR ГРЛС-файлов, но версии явно не всегда совпадают. Следствия: хранить дату/версию как напечатаны, **не заменять** уже имеющийся ГРЛС-текст, пометить класс источника и пересмотреть, когда ГРЛС даст свой файл.

## 5. Способ проверки

Документ принимается в манифест, только если:

1. файл — документ производителя на странице продукта самого сайта держателя (`publisherKind = manufacturer-site`); справочники (РЛС, Видаль, medi.ru), аптеки и агрегаторы не обходятся (в `SITES` нет ни одного такого хоста);
2. в тексте документа **в начале** (первые 1 500 знаков) — торговое название целиком как последовательность слов, не склеенная с `+` (иначе «Ампициллин» совпал бы с «Ампициллин + Сульбактам» — ✔ найдено при отладке, закрыто тестом); название вне начала допускается только при совпадении номера РУ;
3. держатель/производитель назван в тексте;
4. уровень доказательства:

| Уровень | Условие | Принятие |
|---|---|---|
| `text-number` | номер РУ (все форматы печати: `ЛП-№(011241)-(РГ-RU)`, `ЛП-Nº(…)-(PГ-RU)`, `ЛП-006417`, `ЛСР-…`, `П N014329/01`) и название напечатаны в документе, держатель назван | строгое |
| `page-number` | номер РУ напечатан на странице, где лежит документ, название и держатель — в документе | строгое (номер из HTML страницы-источника, сохранённого как доказательство) |
| `label-unique` | номера нигде нет; название в заголовке, форма (и дозировки по возможности) совпадают, из недостающих подходит ровно одна регистрация | **условное**: решение владельца (рекомендация — принимать с пометкой «по этикетке») |
| `label-ambiguous` | то же, но подходят 2+ регистрации | не принимать автоматически; все кандидаты записаны |

Почему нужна ступень `label-*`: правило «номер РУ напечатан в тексте» для ЕАЭС-листков невыполнимо по природе документа (✔ листок Вертекса и ИМП Микрогена без номера). Альтернатива — отбросить 179 из 245 найденных (73 %). Выборочный просмотр 13 случайных `label-unique` (заголовок документа, форма, дозировки и держатель против реестра) ошибок не выявил (это не полная проверка); осталась известная неоднозначность у одноимённых препаратов разных дозировок — она переводит случай в `label-ambiguous`.

Ограничения проверки: сравнение формы — по первому элементу `dosageForm` (префикс 8 знаков), дозировки сверяются по количеству совпавших «число+единица» в шапке, а не по полному разбору; версия сайта может быть не текущей редакцией ГРЛС (см. выше). Состав, показания и дозы текстом не сверялись — их нечем сверять без ГРЛС-файла.

## 7. Рекомендации и ожидаемое покрытие

Что есть: резюмируемый сборщик `tools/ingest/src/localmed_ingest/manufacturer_instructions.py` (+ CLI `manufacturer_instructions_cli.py`, 11 тестов): вежливый клиент (robots по RFC 9309, пауза, CAPTCHA/403/429 → остановка хоста, TLS проверяется), обнаружение страниц по sitemap, разбор карточек, DOCX/PDF, сопоставление с недостающими, манифест с происхождением. Новый сайт — одна запись `Site(key, имя, база, ключи держателя, sitemap, шаблон страниц)`; адаптер не нужен, пока документ — прямая ссылка в статическом HTML.

Решения и порядок:

1. **Владелец решает по `label-unique`** (§5). Если принимать — подключить манифест к подготовке отдельным классом источника (`manufacturer-site`) с бейджем «по данным производителя», приоритет ГРЛС выше.
2. **Дособрать пилотные 7 сайтов целиком** (Реневал: 359 страниц осталось; остальные уже полны) и перепрогонять `rebuild-manifest` после каждого окна G1: набор недостающих сокращается, часть найденного станет не нужна. Ожидание: +30–60 регистраций.
3. **Запрос в НЦЭСМП на 6 415 ЕАЭС-регистраций остаётся главным путём** ([grls-mirrors-2026-10.md](grls-mirrors-2026-10.md) §7); сайты производителей закрывают лишь 3 % недостающих.
4. **Новые сайты добавлять по выгоде**: из топ-30 держателей статичны 7; ещё до ~10 потребуют решения упомянутых блокеров. Динамические сайты (Велфарм, Фармасинтез, Валента) — только через браузерный рендер, что ломает «одного запроса» и усложняет сборщик; отложено. TLS-проблемы чужих серверов не обходить; запросить у владельцев сайтов нельзя — только ждать исправления.
5. Микроген: сайт явно блокирует ИИ-краулеры в `robots.txt` (§3). Файлы уже собраны по правилам `*` (107 документов); продолжать ли обход этого сайта — решение владельца.
6. Адреса сайтов искать вручную по реестру (по одному на держателя), не через общий поиск.

Ожидаемое покрытие (недостающие 8 325; ЖНВЛП 3 102):

| Сценарий | Регистрации | Доля | ЖНВЛП |
|---|---|---|---|
| Пилот, 7 сайтов (факт) | 245 (61 строгих) | 2,9 % | 94 (3,0 %) |
| + дособор Реневала и новых окон | ≈ 300 | ≈ 3,6 % | ≈ 110 |
| + ещё 5–8 статичных сайтов из следующих 30 держателей (○ выход 20–40 %, ~15 регистраций на сайт в среднем) | ≈ 400–450 | ≈ 5 % | ≈ 150 |
| + динамические/TLS-проблемные сайты (○, при готовности браузерного рендера) | ≈ 550–650 | ≈ 7–8 % | ≈ 200 |

Сравнение с G1: ГРЛС-цикл даёт ≤ 50 регистраций в сутки (≈ 1,5 тыс./мес. при стабильной работе); обход 7 сайтов дал 245 регистраций за ~1,2 часа без риска блокировки ГРЛС, но оба пути пересекаются слабо (приоритет G1 — ЖНВЛП, у производителей — то, что выложено).

## 8. Что не проверялось

- Содержательное совпадение текстов с ГРЛС-версией: сравнивались только 32 пары по шинглам; клинически значимые расхождения (дозы, противопоказания) не искались.
- Права на повторное использование текстов сайтов не оценивались: документы лежат локально как сырьё, в приложение/релиз не попадают (политика §«Уровни», см. [REFERENCE_SOURCE_POLICY.md](../REFERENCE_SOURCE_POLICY.md)); условия использования отдельных сайтов не читались, соблюдались только `robots.txt` и вежливость.
- Реневал обойдён на 22 % страниц; КРКА — 216 карточек, но 259 документов отфильтрованы предпроверкой по названию/МНН (она могла пропустить препарат с названием, не похожим на название недостающей регистрации).
- Сайты `tulapharm.ru`, `canonpharma.ru` и др. не обходились (§3); таймаут Канонфармы — следствие сети этой машины, не подтверждение недоступности сайта.
- Нет подтверждения, что веб-поиск по умолчанию типичен для всех поисковиков; результаты — одного инструмента на 20 запросов.
- Интеграция манифеста в сборку пакетов, бейдж и отдельный класс источника в приложении **не сделаны** (только сбор и манифест).
