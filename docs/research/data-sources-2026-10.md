## 1. Главные выводы

1. **Allmed — это Allmed PRO (allmed.pro)**: независимый коммерческий справочник лекарств «с рецептурой» (сайт, приложения Android/iOS с офлайн-базой), не официальный источник
   (✔ allmed.pro/app, /information/rules). В репозитории — приватный снимок SQLite владельца: 4 708 торговых названий (на сайте сейчас «4600+»),
   без номера регистрации, у 100% есть показания, противопоказания, побочные действия, способ применения у взрослых; фармакокинетика, взаимодействия,
   передозировка, особые указания — у ~56–58%, способ применения у детей — у 26% (✔ мой подсчёт по `data/intermediate/allmed-reference-candidates.jsonl`).
   Происхождение текстов сайт не указывает. Условия: «без письменного разрешения ... копирование ... переработка, распространение, публикация ... запрещено», и тут же в подвале «Копировании текстов ... разрешено только при указании ссылки на источник allmed.pro» (✔ тот же URL). Для личной сборки годится, для публикации нет. До «всех ~10 тыс.» не дотягивает по охвату (4,7 тыс. названий) и по глубине (текст короче полной инструкции).
2. **Единственный официальный полный текст инструкций — ГРЛС** (PDF по каждой регистрации; по новым регистрациям ЕАЭС — ОХЛП и листок-вкладыш). Это тот самый источник, который уже скачан на 44% активных РУ.
   **Новая находка: `robots.txt` ГРЛС запрещает автоматический доступ всем роботам** (`User-agent: *` / `Disallow: /`, плюс `Disallow: *.aspx`; ✔ https://grls.rosminzdrav.ru/robots.txt).
   Текущая массовая выгрузка PDF с этим расходится; в репозитории это нигде не зафиксировано. Нужно решение владельца (см. раздел 6). Официальный легальный канал, который ГРЛС называет сам, — «Формирование заявки на предоставление доступа к БД ГРЛС» на главной странице (проверено 2026-10-04: это форма регистрации организации в системе ГРЛС — страна, ОПФ, наименования, исходящий документ — для заявителей/держателей РУ, а не запрос выгрузки данных; частному лицу не подходит).
3. **Закрыть пробелы ГРЛС другим источником «по тому же тексту» нельзя без нарушения условий.** РЛС и Видаль запрещают копирование, Allmed тоже, ОХЛП ЕАЭС отдаются за CAPTCHA (обход запрещён). Легальные варианты: (а) повторная загрузка 6 425 транзитных сбоев из ГРЛС (если владелец решит проблему robots/доступа), (б) коммерческий договор (РЛС Aurora: 18 249 инструкций, цены нет, ◐), (в) ручное/запросное получение ОХЛП у НЦЭСМП. Потолок ГРЛС по текущему плану: из 19 381 целевой регистрации скачано 8 891, ещё 6 425 повторяемых, 4 065 постоянных отказов (старые форматы `ФС-`, `ЛСР-`, `ЛС-`, `Р `, `П `) (○ kb-audit-content §2.2). Грубая оценка: если все повторяемые удастся скачать, получим ~15 тыс. регистраций, а с поправкой на «один PDF на несколько РУ» (8 861 PDF на 12 640 РУ) порядка 10–11 тыс. отдельных текстов (оценка, не измерение).

| **РЛС Aurora** | по условиям договора | — | Обновления по API |
| **ЕАЭС NSI, портал ЕАЭС** | пока недоступен | — | Перепроверить через месяц |

**Правила.**
- Все пробы с `User-Agent`, один запрос на хост за раз, тайм-аут 20 с, повтор один раз; результат и код ответа пишутся в отчёт.
- Выход: 0 — все `current` или `unreachable`; 10 — есть `update-available`; отчёт `data/build/freshness-report.json` + Markdown-сводка для README релиза.
- Расписание: вручную перед релизом; опционально раз в неделю локально (cron), без CI-минут (политика AGENTS.md: данные собираются локально).
- Реестр «что давать в UI» (R1): для КР и ЕСКЛП проверка также печатает, какие документы уже имеют предыдущую редакцию, доступную для скачивания (статус 4, предыдущий снимок ЕСКЛП в списке файлов), чтобы «сравнение редакций» знало, из чего собирать пару.

## 6. Открытые вопросы и что не проверено

- Правовые условия ЕСКЛП на переработку и распространение; текст страницы «для разработчиков» (SPA, сертификат) не перечитан, цитата «безвозмездно и общедоступно» взята из репозитория.
- Любые условия НСИ Минздрава на повторное использование (в паспортах `laws` пусто; страницы условий не нашёл, портал отдаёт SPA на любые адреса).
- Действует ли в НСИ скачивание полных справочников без входа; формат API-ответа и история версий справочника.
- Сопоставление ГРЛС по номеру: правила поиска старых форматов (`ФС-`, `ЛСР-`, `ЛС-`, `Р `, `П `), которые не находятся поиском; кому принадлежат инструкции по ним.
- ОХЛП vs инструкция для всех РУ по правилам ЕАЭС и точное число таких РУ в ГРЛС.
- Стандарты медицинской помощи: полный перечень и форма API pravo.gov.ru.
- Полнота русского перевода МКБ-11 в API ВОЗ.
- Видаль, зарубежные подписи лекарств (DailyMed, EMA), Росздравнадзор, регистры Казахстана и Беларуси: не исследовались.
- Русские текст ЖНВЛП-2025 (распоряжение № 3867-р) на наличие названий групп АТХ: структура проверена по редакции 2018 г.
- Сертификат: прямой запрос ЕСКЛП/НСИ проходит только с корневым сертификатом Минцифры; не проверено, как сейчас настроен сборочный контур.
