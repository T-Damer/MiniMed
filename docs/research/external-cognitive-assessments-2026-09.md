# External cognitive assessments — authoring note

Status: draft implementation in PR #178, dependent on concept-first PR #174.

## Goal

MiniMed needs to represent standardized cognitive/psychodiagnostic instruments without assuming that
their stimulus material, scoring keys, translations or normative tables may be redistributed.

The first draft families are:

- Raven Progressive Matrices — one concept/tool card with CPM, SPM and APM variants;
- Wechsler intelligence scales — one family card with WAIS, WISC and WPPSI variants;
- MMSE — structured capture of a result from an external form.

The user-supplied MMSE examples used while designing the workflow are **not committed** and are not
treated as redistribution permission.

## Product contract

These tools use `externalAdministration.mode = "external"`.

The downloaded MiniMed definition contains only:

- identity and aliases;
- selectable variant metadata;
- schema-driven fields for recording a result;
- limitations and source/licensing metadata;
- a local-material policy.

It does **not** contain protected questions, matrices, stimulus books, answer keys or norm tables.

A clinician may select a local PDF/JPEG/PNG/WebP that they already possess and send that file to the
existing local/native print path. The selected material is not uploaded and is not copied into the
public tool pack.

The saved result is structured (`kind = "external"`) rather than an opaque text note:

```text
assessmentId
variantId
values { fieldId -> string | number }
definitionVersion
subject/date metadata
```

This means Raven can remain one tool while the result still records whether CPM, SPM or APM was used.

## Initial result fields

### Raven

Each CPM/SPM/APM variant records:

- raw score;
- optional percentile;
- exact edition/form;
- norm reference/context;
- optional note.

MiniMed intentionally does not derive the percentile from the raw score.

Pearson's current Raven materials describe separate CPM, SPM and APM products and publish different
target age ranges/completion times. The product/manual used in practice remains the authority for a
specific administration.

### Wechsler

The family card allows WAIS/WISC/WPPSI selection. The result requires the exact edition and can record
the overall reported score plus free-form index scores and norm/language context.

MiniMed does not calculate IQ/index scores from subtest answers and does not attempt to translate one
edition's indices to another.

Official product index:
https://www.pearsonassessments.com/professional-assessments/products/products-a-z.html

### MMSE

The initial draft records the original 30-point MMSE total plus form/translation context and notes.

The PAR product page confirms a maximum raw score of 30 for the original MMSE and lists an authorized
Russian translation. MMSE-2 is a separate family with Standard/Brief/Expanded versions and is not
silently conflated with this initial original-MMSE entry.

Official references:

- MMSE:
  https://www.parinc.com/products/MMSE
- MMSE-2:
  https://www.parinc.com/products/MMSE-2
- PAR permissions/translations:
  https://www.parinc.com/about/connect-with-us/licensing-team/available-par-products

## Printing

Two operations are deliberately separate:

1. **Print result / blank result sheet** — generated by MiniMed from the declarative result-field
   schema and always safe to render locally.
2. **Print test material** — available only after the clinician chooses a local file. MiniMed passes a
   PDF to the existing original-file print/share path or renders a selected local image for printing.

No protected material is embedded in the source repository or generated from the test name.

## Packaging

The authoring module is currently:

`content/tool-modules/drafts/cognitive-assessment.json`

It is intentionally below the normal top-level `content/tool-modules/*.json` release scan, so
`buildToolCatalog.ts` cannot accidentally advertise a downloadable module before an actual SQLite
artifact and catalog descriptor exist.
