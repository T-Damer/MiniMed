# Публичные зеркала и коллекции официальных документов на лекарства: третий обход (2026-10-04)

Задача: найти открыто опубликованные коллекции официальных документов (PDF инструкций ГРЛС `/InstrImg/`, ОХЛП и листки-вкладыши ЕАЭС), которые кто-то уже собрал, чтобы закрыть часть из 8 325 недостающих регистраций. Продолжение [grls-mirrors-2026-10.md](grls-mirrors-2026-10.md) и [instruction-sources-2-2026-10.md](instruction-sources-2-2026-10.md); то, что там уже проверено (Wayback, Common Crawl, medi.ru, HF-набор по РЛС, аптеки, BY/KZ-реестры, сайты производителей), не повторялось.

**Результат: отрицательный. Ни одного публичного зеркала или коллекции официальных документов не найдено.**

Режим: только исследование; запросы к API последовательные, с паузой 3–10 с, User-Agent `MiniMed-research/1.0 (…)`; ни одного файла не скачано (только JSON-ответы поисковых API и метаданные); логины, CAPTCHA и подбор URL не использовались; bucket `firsts3.ru` (medvisement) не перечислялся. Рабочие файлы удалены.

Обозначения: ✔ — проверено запросом в этой сессии; ◐ — по выдаче веб-поиска/описанию, оригинал не читался.
