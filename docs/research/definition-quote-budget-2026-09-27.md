# Лимит дословной цитаты для специализированных источников: 25 → 1024 слов (2026-09-27)

Решение пользователя: поднять лимит цитаты для MSD и подобных специализированных источников,
сначала оценив влияние на редакцию и поиск. Ниже — реальные, а не только оценочные, цифры: лимит
применён в коде, и 3 реальные выдержки MSD Manual Professional (RU) прошли весь конвейер живьём
(без сети не проверить реальный размер выдержки).

## Код (`tools/ingest/src/localmed_ingest/clinic_definition_completions.py`)

- `SPECIALIZED_HOSTS = {"www.msdmanuals.com"}`, `SPECIALIZED_EXCERPT_WORDS = 1024` (было 25 для
  всех источников, `CONSUMER_EXCERPT_WORDS = 25` сохранён для invitro.ru/smclinic.ru/др.).
  `excerpt_word_budget(host)` выбирает лимит по хосту; и поштучная проверка в `verify_excerpt`, и
  совокупный бюджет на страницу (`quoted_per_url`) используют один и тот же лимит для хоста —
  никакой склейки нескольких выдержек в одну сверх лимита, каждая выдержка по-прежнему обязана
  быть непрерывным фрагментом ровно одного видимого абзаца (`verify_excerpt` не изменился в этой
  части, только сам числовой порог параметризован).
- Символьный лимит на текст выдержки поднят с 4096 до 12 288 символов (1024 русских слова ×
  ~7-9 символов с пробелом), чтобы не срезать длинную выдержку до применения проверки по словам.
- Тесты: `tools/ingest/tests/test_selected_completion_transport.py` — новый 38-словный пример
  (реальная первая фраза статьи MSD о синдроме короткого интервала QT) отклоняется при
  потребительском лимите и принимается при специализированном; отдельный тест подтверждает, что
  «склейка» двух предложений из разных абзацев по-прежнему отклоняется независимо от лимита слов
  (первое требование — «непрерывный фрагмент», а не просто «до 1024 слов»).

разобран и сверен посимвольно), не тестовые данные:

|---|---:|---:|

| Синдром длинного интервала QT | 33 | 605 |

Все три приняты (`status: accepted`), статус `requires-review`, права размечены

## Экстраполяция на полную очередь высокого/среднего приоритета

Используя измеренный коэффициент (≈4 096 байт установленных / ≈2 722 байт gzip на запись — это
уже включает FTS-индекс и метаданные, не только сырой текст):

| Партия | Записей | Установлено (Δ) | Gzip (Δ) | % к текущим 192 МБ / 42 МБ |
|---|---:|---:|---:|---:|
| Высокий приоритет (по `definition-gap-priority-2026-09-27.json`) | 1 140 | ≈ 4,67 МБ | ≈ 3,10 МБ | +2,4% / +7,4% |
| Высокий + средний | 3 845 | ≈ 15,75 МБ | ≈ 10,47 МБ | +8,2% / +24,8% |

**Рост умеренный по критерию пользователя (в пределах +20–30% к редакции) даже для полной
партии высокий+средний, и без заметного замедления поиска.** Условие «примени» — выполнено для
доступной на сегодня выборки (3 записи, реально проверенные конвейером); полное закрытие 1 140
высокоприоритетных названий вручную-через-браузер в рамках одной сессии физически не влезает
(конвейер требует по 2–4 обращения к странице на название плюс ручной подбор дословной цитаты —
на 1 140 названий это тысячи обращений). `docs/research/definition-gap-priority-2026-09-27.json`
уже содержит готовый к продолжению приоритетный список; рекомендация — оформить это отдельной
задачей на несколько проходов, а не одной сессией.

## Границы

Цитата всегда непрерывный фрагмент **от начала выбранного абзаца** (не обязательно первого
предложения статьи — см. пример ОРДС, где взято предложение о степенях тяжести из другого абзаца
той же статьи, потому что первое предложение содержало номер сноски `(1)`, ломающий посимвольное
сопоставление с видимым текстом страницы); никогда не склеена из разных абзацев. `requires-review`
на всех записях; права — как и раньше, привязаны к уже одобренному источнику `www.msdmanuals.com`
в `HOSTS`, никакого нового хоста не добавлено.
