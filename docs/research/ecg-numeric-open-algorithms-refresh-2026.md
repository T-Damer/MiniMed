# Числовая диагностика ЭКГ: повторный open-source поиск (31.08.2026)

## Короткий вывод

Готового permissive-пакета «табличные измерения 12 отведений → широкий набор диагнозов» не найдено. Практически пригодная архитектура для MiniMed остаётся гибридной: собственные проверяемые правила по подтверждённым числам и морфологии, плюс небольшой вероятностный классификатор, обученный только на общем наборе доступных признаков. При неполных или фото-извлечённых данных нужен `abstain`, а не угадывание.

## Что можно реально реализовать

1. **Слой качества и происхождения.** Для каждого поля хранить значение, единицу, источник (`manual`, `digitized`, `device`), confidence и `missing/contradictory`. Любое фото-извлечение автоматически ограничивать статусом `needs review`.
2. **Детерминированные правила.** Расширять только формальные узкие паттерны с полным набором входов. Текущий LAFB-срез требует axis + QRS + qR/rS + aVL R-peak-time и явных suppression fields; неполный набор даёт `abstain`.
3. **Вероятностный numeric слой.** Обучить RF/HGB/логистическую регрессию на PTB-XL+ только по пересечению признаков, которые MiniMed действительно получает и может проверить. Калибровать на validation fold; выдавать вероятности гипотез, не «диагноз».
4. **Comparator-only контур.** RECGDT и Construe запускать вне браузерного runtime на WFDB-примерах, чтобы сравнивать измерения/выводы и находить регрессии. Их лицензии и несовпадающие входные контракты исключают простое копирование.

## Что не найдено

Не найдено открытого алгоритма, который одновременно принимает уже готовые PR/QRS/QT/QTc, axis, per-lead amplitudes/morphology и возвращает широкий набор калиброванных диагнозов с понятной лицензией. Публичные машинные руководства раскрывают feature contracts и suppression order, но не всю executable rule base. Поэтому «добыть список параметров аппарата» реально; «добыть сам диагнозатор» — обычно нет.

## Практическое решение для MiniMed

Не добавлять ещё одну CNN. Фиксировать numeric schema и abstention, расширять правила небольшими проверяемыми вертикальными срезами, а PTB-XL+ использовать для отдельного исследовательского numeric classifier. RECGDT остаётся самым полезным внешним comparator, Minnesota/NOVACODE и аппаратные manuals — источниками требований и provenance. Новый `ecg-interpreter` не использовать: дата публикации не компенсирует неполные клинические критерии.
