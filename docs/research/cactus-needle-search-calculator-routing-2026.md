# Cactus Needle: search and calculator routing (2026-09-02)

## Короткий вывод

Needle 2 — маленькая on-device модель для tool calling и структурированного extraction, а не поисковый индекс, медицинская база или калькулятор. Она может быть тонким маршрутизатором: извлечь из русской фразы возраст/массу/препарат и вызвать заранее объявленный `calculate_paracetamol_dose` или `search_medication_source`. Сам расчёт, выбор проверенной дозы и выдача цитаты должны оставаться детерминированными MiniMed. Это вывод из API и архитектуры Needle, а не заявленная медицинская возможность.

## Что подтверждено первоисточниками

- Репозиторий описывает Needle 2 как открытую 45M-параметрическую модель для вызова инструментов, управления устройством и структурированного извлечения; опубликованный бинарник — 14 MB, сессия — около 28 MB RAM. [README, строки 3–13](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/README.md#L3-L13)
- Контракт — текстовый запрос → JSON-вызов функции; схема инструмента компилируется в byte-level grammar. Needle не выдаёт свободный ответ при отсутствии подходящего объявленного инструмента: возвращает пустой список вызовов. [API, строки 99–106](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L99-L106)
- `agent.run()` сам выполняет Python-функции и подаёт их результат обратно модели; `complete()` позволяет MiniMed самому контролировать каждый шаг. Схемы можно передавать как декорированные функции, Pydantic-модели, JSON Schema или JSON-строку. [API, строки 3–11 и 70–80](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L3-L11) [API, строки 70–80](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L70-L80)
- При более чем пяти инструментах встроенный contrastive head в каждый ход встраивает запрос и схемы, выбирая только пять лучших; невыбранный инструмент недоступен. `tool_index_path` сохраняет такие embedding-и на диске по fingerprint схем и модели. Это инструментный retrieval, не retrieval медицинских документов. [API, строки 146–148](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L146-L148)
- Инференс после однократной доставки engine не обращается к сети; поддерживается air-gapped установка. Документация Python API перечисляет desktop/server wheel tags и `NEEDLE_LIB_PATH`, а официальный model card также заявляет Android и WebAssembly; сайт запускает модель через WebAssembly в браузере. [API, строки 156–164](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L156-L164) [model card](https://huggingface.co/Cactus-Compute/needle2) [Needle](https://cactuscompute.com/needle)
- Публичный high-level API — Python-пакет с Python >=3.9 и `huggingface_hub`; training extra добавляет JAX/Flax. Поэтому подключение к SolidJS/TypeScript MiniMed потребует собственного адаптера к опубликованному WASM/native engine, а не установки Python в приложение. [pyproject.toml, строки 1–19](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/pyproject.toml#L1-L19)
- Английская/мультиязычная пригодность не доказана для русского. Официальная документация прямо предупреждает, что для non-English deployments confidence следует считать осторожно: для корректных Spanish calls измерялось confidence 0.0; non-English фрагменты занимают примерно 1.7× больше токенов (измерено на Spanish). Русский отдельно не измерен. [Fine-tuning, строки 80–84](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/finetuning.md#L80-L84)
- Официального требования или механизма «перевести запрос на английский» нет. API принимает обычный `query` и отдельно поддерживает только системные факты вроде `locale`; перевод поэтому был бы внешним дополнительным слоем и потенциальным источником потери единиц, отрицаний и контекста. [API, строки 136–144](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L136-L144)
- Confidence — два сигнала, но калибровка заявлена для base model; для fine-tuned weights она отключается (`None`). Документация рекомендует действовать только выше выбранного порога, а ниже эскалировать/переспрашивать. [API, строки 150–154](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L150-L154)
- Код репозитория и официальный model card помечены Apache-2.0. Перед релизом всё равно нужен обычный dependency/license review конкретных распространяемых engine/weights artifacts. [LICENSE, строки 1–6](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/LICENSE#L1-L6) [model card](https://huggingface.co/Cactus-Compute/needle2)

## Пример с парацетамолом

Для запроса `Доза парацетамола ребенку 6 лет 12кг` безопасная схема могла бы быть:

1. Уже существующий MiniMed parser извлекает `age=6 лет` и `weight=12 кг`, а словарь aliases разрешает название препарата; затем приложение проверяет обязательные поля.
2. Needle (если локально квалифицирован и запрос разрешён) получает небольшой закрытый набор инструментов, например `lookup_paracetamol_source` и `calculate_paracetamol_dose`. Описания и enum/границы можно задать JSON Schema; grammar не даст произвольные значения вне схемы. [API, строки 13–15 и 34–49](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L13-L15) [API, строки 34–49](https://github.com/cactus-compute/needle/blob/205b8f0d9fda2ea2d4a886bba8c2d96e21de1b17/doc/apis.md#L34-L49)
3. MiniMed исполняет только типизированный вызов: ищет действующий источник в установленном `medications.db`, затем детерминированный калькулятор считает по данным источника, ограничивает разовую/суточную дозу и возвращает exact source chunk/anchor. Needle не должен получать право считать, выбирать дозу из памяти модели, писать в pack или обходить отсутствие источника. Текущая карточка парацетамола MiniMed содержит идентичность формы и концентрацию `120 мг/5 мл`, но прямо не содержит режима дозирования; из одной концентрации индивидуальную дозу получить нельзя.

Это означает: английский перевод не нужен как условие интеграции, но русский routing нельзя считать работающим по README. Нужен собственный held-out тест на русском, включая падежи, `кг`, десятичные значения, отрицания и неполные данные; до такого теста лучше оставить Needle экспериментальным fallback, а не частью обязательного offline search path.

## Решение для MiniMed

Сейчас не интегрировать Needle в production browser path. Его можно оценивать позже как опциональный локальный adapter только для bounded intent/argument extraction, вызывающий существующие ports. Приоритет остаётся за текущим детерминированным Russian parser → SQLite source retrieval → typed calculator: это сохраняет offline-first контракт, точную provenance и контролируемое медицинское поведение. Needle может помочь с маршрутизацией, но не заменяет индекс, источник или калькулятор.

Open questions: русская accuracy/latency/memory на Android/iOS/WASM adapter; точный стабильный API этих runtime artifacts для MiniMed; clinician-reviewed safety benchmark для tool selection и argument grounding.
