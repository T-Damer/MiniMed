- **Нигде в метаданных КР нет признака OCR**, потому что ни одна КР не распознавалась. Поле «режим извлечения»
  `textExtractionMode` (`pdf_text_layer` | `ocr`) пишет только `tools/ingest/src/localmed_ingest/pdf_import.py`
  (строки 474-520, 655-711) в диагностику рабочего каталога; в 723 диагностиках КР
  (`data/build/official-clinical-documents/workspaces/*/.localmed/diagnostics/*.json`) этого ключа нет, а в
  `prepare-report.json` (723 файла) строк про OCR 0. То есть по PDF-ветке КР не записано, текстовый слой это
  или OCR (пробел в происхождении).
- Конфигурация плана источников включает `ocrFallback: true, ocrLanguage: rus+eng, ocrDpi: 200`
  (`data/build/official-clinical-source-plan/registries/*.yaml`), но для `format: clinical_json` она не используется.
- Внешний «AI OCR» (Replicate Marker, Qwen) применялся только к книгам из `Med/` (`docs/LITERATURE_OCR_STATE.md`,
  `docs/OCR_QWEN_WORK_TRACK.md`), не к КР.

### 1.3. Эвристики (дёшево и воспроизводимо)

Считаются на `chunks.original_text` (поставляемый JSON, 744 док., 108,0 млн знаков, 69,3 млн кир. букв),
на `chunks.original_text` PDF-баз (723) и на сыром тексте слоя PDF (PyMuPDF `get_text`, 744).

| Сигнал | Определение |
|---|---|
| homoglyph | слово из ≥4 строчных кириллических букв с 1–2 латинскими «двойниками» (`a c e o p x y i u`, заглавная только в начале); исключены обозначения `ИМпST`, `QT`, классы `IIaC`, сноски `…A` |
| glued (склейка) | `[а-яё]{3}[А-ЯЁ][а-яё]{2}`: конец одного фрагмента слит с началом следующего («баллаРеакция») |
| hyphen_break | `слово- слово` без союза или `слово-⏎слово` |
| long_word | кириллическое слово ≥31 буквы |
| run-on | `слово.Слово`, `слово,слово` без пробела |
| soft_hyphen / PUA / □ / ctrl | U+00AD; U+E000–F8FF; □■; управляющие и нулевой ширины |
| rare-word rate | доля слов ≥4 букв, встречающихся ровно в одном документе набора (проксимальная мера опечаток; считается отдельно по каждому набору, документы ≥300 слов) |
| ATC-кириллица | кодов вида `АТХ X00XX00`, в которых есть кириллические буквы |

Индекс повреждения (на 10 000 кир. букв): `(5·homoglyph + 2·glued + 2·hyphen + 2·long_word + 1·run-on + 0,2·soft_hyphen + 1·PUA + 1·□ + 10·ctrl) / (кир.букв/10⁴)`.
Веса произвольные, индекс годится для ранжирования, не как оценка качества. Ложные срабатывания: сноски вида
`терапияo` (латинская «o» как надстрочный знак), шкалы, где «склейка» легитимна.
