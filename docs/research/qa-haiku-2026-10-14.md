## Data safety
- **Typed note text lost on reload** ×2: a visit note typed in a patient card («Краткая запись осмотра», then
  «Создать осмотр», reload → empty; text in an open visit also lost, ✓ does not keep it); a plain note lost on reload
  in 2 of 4 tries when reloading 4–6 s after typing; no unsaved warning. [NOTE1]
- «Создать осмотр» twice creates a second open visit; ✓/✕ icons clip the status text. [NOTE1]

## Navigation (back must return where the user came from, state intact) [NAV1]
- In-app ‹ pushes a history entry instead of going back (calculator, calculator list, ATC list, deep-linked tools):
  browser back then replays the screen just left; double-tap ‹ likewise. The reader's ‹ pops correctly.
- Reader header «Поиск» replaces the reader's history entry: one back leaves the app.
- «?» help sheet and «Раздел поиска» sheet are not history layers: browser/Android back exits the app (ATC sheet and
  «Рецепт» do it right). Inline link preview: back leaves the guideline instead of closing the preview.
- Outline jump to a section is not a history step: back from 3.1.1 goes straight to search, guideline position lost.
- Bottom-tab switches: back after a switch is inconsistent (skips a tab, or exits the app).
- Scroll positions not restored reliably (search results 900 → 0; guideline 12 065 → 10 897).
- ATC list ‹ labelled «К базе знаний» climbs one ATC level per press and never returns to the drug; returning from the
  ATC list shows a phantom step (drug top, then drug scrolled to the ATC row).
- Interaction checker loses both selected drugs on any navigation or tab round-trip (comparison keeps them in the URL).
- No way into a drug screen from the interaction checker chips or the comparison column title.
- «В12», «С3» etc.: fine. Malformed document link `#/modules/documents/d/%%%` → blank grey screen [DOC-UI1].
- A second tab blocks the whole app with no «use here» action.

  comparison screens; the ATC tree shows 14 «Скачать · X МБ» buttons with ragged widths; ATC tree group shows
  «1 подгруппа · 1 вещество» while not downloaded. Copy «скачайте её ниже» while the button is above.
- A first-ever visit offline stays blank and does not retry on reconnect.

## Search quality [SRCH1]
- Complaint search on the minimal install: «боль в животе справа» → a rare appendix anomaly first (clinical mode:
  asthma first, appendicitis not in top 6); «сыпь после антибиотика» → rickettsial fever, no drug reaction; «кашель и
  температура у ребенка 3 года» → asthma first. Results do not say they are keyword-only; the 130 MB meaning model offer
  is the only hint. (Not tested with the model installed.)
- Brand «Аспирин» → no drug card in the main search (the interaction picker maps it). «варфарин» ranks two calculators
  above the drug card. «Препараты» scope returns homeopathic Latin mixtures first for common queries.
- Interaction picker finds nothing for «сакубитрил» or «сакубитрил/валсартан» (only «валсартан+сакубитрил»); picker
  matches only from the start of a name.
- Class words («макролиды») return documents mentioning the class, not the class members (owner question pending).
- «ИМТ» result labelled «Калькулятор» opens a reference document. «Есть новые результаты · Обновить» appears after
  back with no explanation. Search highlights break mid-word; «J05» highlights words not in the query.
- Nonsense input (`<script>…`) returns fuzzy matches instead of «Ничего не найдено». Search query not in the URL.
- Dictionary lookup shows loose matches («Расстройство расщепления личности» for «национальный»).
- Data: «Вейника наземного трава+щучки дернистой трава» listed under J05; ATC level-5 sheet lists strengths twice
  («100.0мг» and «100 мг») [DRUG-UI1]; J05AX INN names with lowercase Latin fragments, IUPAC names.
