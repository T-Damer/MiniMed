# Prototype status

The public MiniMed prototype includes two independently tested local workflows:

- psychology and psychodiagnostic questionnaires with local history, printing, sharing, and patient-note export;
- sourced medical calculators with explicit units, formula traces, limitations, local history, printing, sharing, and patient-note export.

Pull-request E2E tests validate each workflow against a built application. The `Live Pages prototype smoke` workflow separately validates the deployed GitHub Pages application after every successful Pages deployment.
