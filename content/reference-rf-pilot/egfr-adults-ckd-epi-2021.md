# Область применения

<!-- localmed:source {"officialUrl":"https://www.niddk.nih.gov/research-funding/research-programs/kidney-clinical-research-epidemiology/laboratory/glomerular-filtration-rate-equations/adults","sourceSection":"eGFR Equations for Adults","contentMode":"paraphrase"} -->
NIDDK рекомендует безрасовые формулы CKD-EPI для оценки скорости клубочковой фильтрации у лиц 18 лет и старше. рСКФ является расчетной оценкой, а не точным измерением функции почек; динамика, рассчитанная одной и той же формулой, обычно информативнее одной точки.

# Формула CKD-EPI 2021 по креатинину

<!-- localmed:source {"officialUrl":"https://www.niddk.nih.gov/research-funding/research-programs/kidney-clinical-research-epidemiology/laboratory/glomerular-filtration-rate-equations/adults","sourceSection":"2021 CKD-EPI Creatinine Equation","contentMode":"paraphrase"} -->
Формула для стандартизованного креатинина сыворотки:

`eGFR = 142 × min(SCr/κ, 1)^α × max(SCr/κ, 1)^−1.200 × 0.9938^Age × 1.012`, если пациентка женского пола.

Здесь eGFR выражается в мл/мин/1,73 м²; SCr — креатинин в мг/дл; κ = 0,7 для женщин и 0,9 для мужчин; α = −0,241 для женщин и −0,302 для мужчин; Age — возраст в полных годах. Для мужчин множитель 1,012 не применяется.

# Перевод единиц креатинина

Для перевода креатинина из мкмоль/л в мг/дл значение делят на 88,4. Формула предполагает креатинин, стандартизованный относительно IDMS; ввод значения в других единицах без перевода даст ошибочный результат.

# Когда предпочтительны креатинин и цистатин C

<!-- localmed:source {"officialUrl":"https://www.niddk.nih.gov/research-funding/research-programs/kidney-clinical-research-epidemiology/laboratory/glomerular-filtration-rate-equations/adults","sourceSection":"2021 CKD-EPI Creatinine-cystatin C Equation","contentMode":"paraphrase"} -->
Совместная формула по креатинину и цистатину C в среднем точнее формулы только по креатинину. Она особенно полезна, когда результат близок к порогу клинического решения — например, при подборе дозы отдельных лекарств или оценке кандидата на трансплантацию — либо когда на один из маркеров влияют неклубочковые факторы.

# Ограничения

Формула не заменяет измеренную СКФ и хуже работает на высоких значениях фильтрации. Острые изменения функции почек, нестабильный креатинин, крайняя мышечная масса, ампутации, выраженное истощение и некоторые лекарства требуют осторожной интерпретации. Для возраста 18–25 лет NIDDK рекомендует сопоставлять взрослую CKD-EPI и CKiD U25, особенно при хронической болезни почек.
